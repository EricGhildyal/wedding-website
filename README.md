# Wedding Website

Custom website I built for my wedding after testing out a bunch of off-the-shelf ones that didn't meet my expectations. Pretty basic React App using Netlify functions as a backend to interface with the Notion API.

## `yarn start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload if you make edits.\
You will also see any lint errors in the console.

## Netlify functions

Contained in the `netlify/functions` directory
